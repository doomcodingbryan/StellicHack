# StellicHack Pathfinder

Pathfinder is an application used for career planning and skill development. It is meant to help students understand and develop their academic and technical experience, and fulfill their career goals. 

Users on the platform will be able to add in their own paths that they took in order to get the current job that they have or be in the current position they are in. 
Students will be able to see pathways of alumns from their school and be able to be matched with pathways that they could follow that align with their interests the most. It will also compare students and their current experience, skills, courses, etc. with the alumni inforomation. The application will show where the student is lacking in comparison and what would be in their best interest to improve on, what classes to take, etc.

# Project Status

The project is currently in the backend/API development and frontend integration phase. 

The backend provides the foundation for: 

- User registration
- User authentication
- JWT login
- Student profiles
- Institutions
- Degrees
- Courses
- Careers
- Skills
- Career skill requirements
- Career matching
- Gap analysis in skills
- Student and Alumni matching
- Career pathway generation
- PostgreSQL database integration
- Dockerized dev environment

These features will be expanded upon in future development.
